# v1.14.0 update delivery test

This release-only PR changes no application behavior. The declared minor release
from stable v1.13.0 automatically produces v1.14.0-beta.<run>.<PR>.<attempt>.

After the PR's Actions run succeeds:
1. On installed stable v1.13.0, enable Settings → Updates → Include beta releases.
2. Exit Evict completely and restart with automatic update checks enabled.
3. Confirm the top-right button shows Update to v1.14.0-beta.<run>.<PR>.<attempt>.
4. Download and install the update; confirm the installed version after restart.
5. With beta updates disabled, stable v1.13.0 must not offer this beta.

After merging this PR into main and its Actions run succeeds:
1. Confirm GitHub publishes stable win-v1.14.0.
2. Restart the installed beta and confirm the button shows Update to v1.14.0.
3. Install the stable update and confirm v1.14.0 after restart.

The workflow manages version files, tags and release assets automatically.
Published-update discovery, checksums, native installers and archive layout are
verified by CI. Actual GUI behavior must be checked on the installed application.
