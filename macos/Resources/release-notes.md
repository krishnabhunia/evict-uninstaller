# What's new in Evict for macOS

- The Home dashboard, application filters, orange adaptive interface and startup progress bring the approved Windows experience to the native Mac app.
- Software Updater checks Homebrew casks, supports selected updates and saved exclusions, verifies results and keeps seven days of update history.
- Evict Versions offers exact macOS stable and beta releases, readable three-digit betas, implementation notes, pinned versions, verified downloads and recovery copies.
- Daily and weekly scans use a verified per-user macOS schedule with explicit Apply; background scans inspect your system without removing files or installing updates.
- Cleanup reviews caches and logs before moving selected entries to Trash; browser management, installation snapshots and security information are available in Tools.
- The menu-bar menu and Command-K search provide quick access, and running applications must be closed before their files are removed.
- Existing preferences survive upgrades, and failed saves and stalled package commands are reported accurately.

macOS uses Homebrew, launchd, Finder, Trash and native System Settings. Windows Registry, Defender and Windows Update removal are specific to Windows. Verified app installation and recovery finish through Finder, and completion is confirmed when that copy is opened.
